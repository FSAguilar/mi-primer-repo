# Agenda de contactos 

Proyecto de práctica de Git.

## Cómo usar

Este repositorio contiene una agenda personal de ejemplo para practicar Git.

1. Abre contactos.txt para consultar los contactos registrados.
2. Abre tareas.txt para revisar las tareas pendientes.
3. Abre compras.txt para consultar la lista de compras.
4. Edita los archivos de texto para actualizar su contenido.
5. Utiliza Git para registrar y consultar los cambios realizados.

## Estructura del repositorio

- README.md: presentación e instrucciones del proyecto.
- contactos.txt: nombres, teléfonos y correos electrónicos.
- tareas.txt: lista de actividades pendientes.
- compras.txt: productos que se necesitan comprar.
- .gitignore: archivos y carpetas que Git debe ignorar.

## Comandos útiles

- git status: muestra el estado del repositorio.
- git log --oneline: consulta el historial de commits.
- git branch: muestra las ramas locales.
- git switch: permite cambiar de rama.
